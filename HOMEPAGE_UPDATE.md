# Homepage update (unpublished branch)

Branch: `homepage-update` — **do not publish** until reviewed.

## Connect as a duplicate theme (safe workflow)

1. In Shopify Admin → **Online Store → Themes → Add theme → Connect from GitHub**
2. Select `RoyalBeing/RoyalBeiing`, branch **`homepage-update`** (not `main`)
3. Preview that theme — leave the live theme on `main` untouched
4. Publish only after approval

## After connect — Theme Editor checklist

- [ ] Assign hero slide images (desktop + mobile) for all 3 slides
- [ ] Confirm collection handles on showcase cards (royal, signature, common, royal-duke, royal-kid)
- [ ] Upload brand video + Watermelon Fusion video to **Shopify Files** (or Content → Files) and paste MP4 URLs into Video / Product spotlight sections (files are ~47MB and ~128MB — too large for theme assets)
- [ ] Select Watermelon Fusion product in Product spotlight
- [ ] Point subscription button to your subscription app / eligible collection
- [ ] Point review buttons to your review app or Reviews page
- [ ] Confirm FAQ / About / Reviews pages exist or update links
- [ ] Assign Ambassador image (crop out mood-board text if using raw client art)
